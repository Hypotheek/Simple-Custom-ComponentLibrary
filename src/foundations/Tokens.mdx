# Design tokens

Design values are CSS custom properties on `:root`, defined in `src/tokens.css` and loaded with the library stylesheet. Use them with `var(--name)`.

## Colors

| Token | Value | Use |
| --- | --- | --- |
| `--color_primary` | `#1d4ed8` | Primary brand color |
| `--color_secondary` | `#475569` | Secondary color |
| `--color_terciary` | `#0f766e` | Third accent color |
| `--color_surface` | `#ffffff` | Component background |
| `--color_surface_muted` | `#f3f4f6` | Hover and subtle backgrounds |
| `--color_border` | `#e5e7eb` | Borders and dividers |
| `--color_text` | `#111827` | Body text |
| `--color_text_muted` | `#6b7280` | Secondary text |
| `--color_danger` | `#dc2626` | Errors and destructive actions |
| `--color_success` | `#16a34a` | Success states |
