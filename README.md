# simple-vue-components

A Vue 3 component library of 155 `S`-prefixed components — widgets (`SButton`, `SCard`, `SModal`, `SSelect`, `SBarChart`, ...) and generic layout primitives (`SFlex`, `SGrid`, `SStack`, `SBox`, ...). Documentation lives entirely in [Storybook](https://storybook.js.org/) — there's no separate docs site to keep in sync.

This branch is a plain base: installing it only gives you the compiled library. It does not add skills, `AGENTS.md`/`CLAUDE.md`, or an MCP config to the project you install it into.

## Install

```bash
npm install github:Hypotheek/Simple-Custom-ComponentLibrary#ab-test-base
```

npm clones the branch and runs its `prepare` script (`npm run build`) itself, so `dist/` is built on install. Pin to a commit instead of the branch name for a reproducible install:

```bash
npm install github:Hypotheek/Simple-Custom-ComponentLibrary#<commit-sha>
```

You need read access to the GitHub repo (an SSH key or a token for GitHub over HTTPS). The install takes a while because npm installs this repo's own `devDependencies` (Vite, Storybook, Playwright, ...) in a temp clone before it can build.

Only `dist/` ends up in your `node_modules` — no component source.

Then register the plugin and import the stylesheet (it includes the design tokens) in your app's entry file:

```js
import { createApp } from 'vue'
import App from './App.vue'
import SimpleVueComponents from 'simple-vue-components'
import 'simple-vue-components/style.css'

createApp(App).use(SimpleVueComponents).mount('#app')
```

Every `S*` component is now available globally in templates.

## Storybook and MCP

Component docs, design tokens and usage examples are in this repo's Storybook, and `@storybook/addon-mcp` exposes them as MCP tools (`docs-list`, `docs-show`, ...). The MCP endpoint only exists while the Storybook dev server runs, so it is not part of the installed package:

```bash
npm run storybook   # http://localhost:6006, MCP at http://localhost:6006/mcp
```

Point your AI tool at that URL yourself if you want it.

## Developing this library

```bash
npm install
npm run storybook       # browse every component and its docs
npm run stories         # regenerate src/components/*.stories.js after adding/renaming a component
npm run build           # rebuild dist/ and src/index.js
```

Add a component by dropping a new `S*.vue` file in `src/components/`, adding it to the right category in `scripts/categories.mjs`, and running `npm run stories`.
